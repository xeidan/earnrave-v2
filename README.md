# EarnRave v2 — starter

Fresh responsive frontend foundation using Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion and Lucide.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3003. The dev script uses port 3003 to avoid common local apps on port 3000.

## Included
- Desktop/mobile navbar and animated product switcher
- Landing page: hero, dashboard preview, feature grid, Journal, Funding, Academy, Tools, AI Coach, workflow, FAQ, pricing placeholder, CTA and footer
- Working product state switcher, mobile menu and FAQ accordions
- Illustrative dashboard preview (no live trading/account data)
- Starter logo at `public/logo.svg`; replace it with your existing EarnRave logo if desired

This is a UI scaffold, not a connected financial product. Auth, imports, AI, billing, provider integrations, data persistence, and any real trading features must be built and connected before launch.
